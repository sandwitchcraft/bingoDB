# BingoDB

A global database of international waste management sorting standards, orginized by national, provinicial, territorial and municipal sorting standards.

Data is pulled from Notion and automatically placed into appropriate subdomain folders, and used to support the Bingo app.

## Files

- `index.json` — the list of regions that exist (GitHub Pages can't list directories, so the app discovers regions here).
- `items.json` — the **global item registry**: one entry per item id with its display name, search keywords and material family. Region files key into it; the registry owns what an item *is*, a region owns which *bin* it goes in. Generated by `registry_to_json.py` from the registry CSV export (`excels/`).
- `data/<country>/<province>/<region>/<region>.json` — one self-contained rules file per region, generated by `csv_to_json.py` from a Notion export. `notices` and `plastics` in those files are hand-edited (no Notion source yet) and survive a regeneration.

`registry_to_json.py` also reports every region key the registry doesn't define or names differently, so drift between the two is visible on every run.
